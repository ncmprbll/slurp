# Dox your opponents

This simple program fetches player's chat history from cstracker. The `<TARGET>` can be either SteamID32 (`STEAM_*:*:***`) or SteamID64 (`765***`).

# Usage

```
Usage: slurp [OPTIONS] --target <TARGET>

Options:
  -t, --target <TARGET>          Target SteamID
  -u, --user-agent <USER_AGENT>  User agent for a web request
  -h, --help                     Print help
  -V, --version                  Print version
```
